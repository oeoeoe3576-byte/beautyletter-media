# beautyletter-media (비공개)

뷰티레터 릴스 작업 파일 중 공개 저장소(ongrowth)에 올리면 안 되는 것들을 보관한다.
- `<레터 폴더>/img/src_*` : 기사·인스타 사진 (ongrowth의 `design/beauty_news/letters/<폴더>/img/`로 복사해서 사용)
- `<레터 폴더>/reel_music.mp4` : 무료 음원을 넣은 자동 업로드용 영상 (→ `letters/<폴더>/output/auto/reel_music.mp4`)
- `<레터 폴더>/upload/` : 업로드 키트(썸네일·영상·캡션)
- `_fonts/Uiyeun.woff` : 온글잎 의연체(재배포 금지 → 이 비공개 저장소에만) → `design/beauty_news/fonts/local/`
- `_music/*.mp3` : Kevin MacLeod 음원 (CC BY 4.0, 캡션에 출처 필수)

복원: ongrowth의 `design/beauty_news/AUTO_UPLOAD.md` 참고.
